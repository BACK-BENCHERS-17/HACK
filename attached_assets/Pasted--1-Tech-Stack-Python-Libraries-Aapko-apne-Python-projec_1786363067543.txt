 1. Tech Stack (Python Libraries)
     Aapko apne Python project me ye libraries use karni
     chahiye:
      * IMAP Client: imapclient (standard imaplib se zyada
        friendly aur clean hai)
      * Email Parser: mailparser ya Python ka built-in
   email
        package.
      * QR Generator: qrcode (with pillow to generate
   base64
        images instantly).
      * Async Wrapper: Built-in asyncio (blocking network
        tasks ko threads me chalane ke liye
   asyncio.to_thread
        ka use hoga).
      * Database (Optional): supabase-py ya motor (MongoDB
        async) ya sqlite3/aiosqlite.

     2. Core Functional Requirements (Python Version)

     F-1: Non-Blocking IMAP Searches (Sabse Important)
      * Requirement: Gmail IMAP checks ko background
   threads
        me execute karna taaki jab ek user verification
        command chalaye, toh baaki users bot ko bina kisi
   lag
        ke use kar sakein.
      * Implementation:
   asyncio.to_thread(sync_imap_function,
        ...) ka use karke.

     F-2: Base64 QR Code Generator in Python
      * Requirement: User ke details lekar instantly UPI
        format QR Code image (PNG/Base64) generate karna
   bina
        server par local file save kiye (in-memory buffer
        implementation).

     F-3: Regex Parsing (Indian Timezone Support)
      * Requirement: Email body me se Amount, UTR, aur
   Sender
        Name extract karna.
      * Timezone Handing: Email ka standard header
   timestamp
        (UTC/GMT) ko India Standard Time (IST) me convert
        karke 15-minute validity verify karna.

     Python-Specific Troubleshooting Guide: Aapka Bot Kyun
     Fail Ho Raha Hai?

     Agar aapne pehle se Python me implementation ki hai
   aur
     wo work nahi kar rahi, toh in Python-specific issues
   ko
     double check karein:

     1. Blocking Event Loop (The Big Freeze)
      * Problem: Python bot libraries single-threaded hoti
        hain. Agar aap imaplib.IMAP4_SSL ko seedhe async
   def
        ke andar call karenge, toh jab tak connection
   complete
        nahi hoga tab tak bot ka event loop block ho
   jayega
        aur bot crash/timeout dega.
      * Fix: Hamesha IMAP call ko sync function me rakh
   kar
        asyncio.to_thread() ke through call karein (jaise
   upar
        ke code me bataya gaya hai).

     2. Timezone-Naive Datetime Comparison Crash
      * Problem: Python me naive datetime (jisme timezone
   nahi
        hota) aur timezone-aware datetime (GMT/UTC) ko
   compare
        karne par crash ho jata hai: TypeError: can't
   compare
        offset-naive and offset-aware datetimes.
      * Fix: Date parsing ke liye standard library
        email.utils.parsedate_to_datetime ka use karein,
   jo
        timezone-aware object deta hai, aur use
        datetime.now(timezone.utc) ke sath compare karein.

     3. Multipart Email Body Extraction Issues
      * Problem: Gmail messages standard strings nahi
   hote. Wo
        HTML aur Multipart formats me hote hain. Agar aap
   body
        ko direct .get_payload() karenge, toh empty list
   ya
        garbage codes mil sakte hain.
      * Fix: Email ke parts me iterate karke specifically
        text/plain payload ko decode karna zaroori hai
   (jaise
        blueprint code me email_msg.walk() use kiya hai).

     4. Raw Bytes Decoding Crash
      * Problem: IMAP emails bytes format me retrieve hote
        hain. Direct decoding utf-8 karne par emojis ya
        special characters (jaise ₹) ki wajah se code
   crash ho
        jata hai: UnicodeDecodeError.
      * Fix: .decode('utf-8', errors='ignore') ka use
   karein
        taaki decoding safely ho jaye
